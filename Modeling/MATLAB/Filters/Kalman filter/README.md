 نظرة عامة
هذا المشروع يقدم تنفيذًا كاملاً لمرشح كالمان (Kalman Filter) لتقدير الموقع والسرعة للطائرات المسيرة (UAV) باستخدام MATLAB. يهدف الكود إلى:
✅ تصفية ضوضاء المستشعرات (GPS، مقياس التسارع)
✅ تقدير الحالات غير المقاسة مباشرة (السرعة)
✅ توفير بنية قابلة للتعديل والتوسع
✅ التعامل مع فقدان الإشارة المؤقت
